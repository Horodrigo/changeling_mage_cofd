# Books and edition policy

## Canonical catalog

Primary catalog:
https://codexofdarkness.com/wiki/Books

Repository-local offline catalog:
`pdfSources/codexofdarkness.com/wiki/Books.html`

Official source PDFs and the complete offline Codex mirror are stored under `pdfSources/`. Prefer this local library for research; use the live catalog when the mirror is insufficient or freshness matters.

The Codex of Darkness Books page is the canonical catalog for deciding whether a published CofD source is eligible for this project.

## Eligibility rule

Use a book as rules authority only when its `Rule Version` in the catalog is:

- `2`
- `1 & 2`

Reject a book marked only:

- `1`

unless the user explicitly requests first-edition material, historical comparison, or conversion guidance.

This rule is about **rules authority**. A first-edition-only book may still be mentioned as historical context when the task explicitly calls for it, but its mechanics must not silently enter a second-edition implementation.

## Important naming ambiguity

Chronicles of Darkness was previously marketed under "World of Darkness" / "new World of Darkness" naming. Do not classify a source by the words "World of Darkness" alone.

Likewise, do not confuse:
- Vampire: The Requiem with Vampire: The Masquerade
- Werewolf: The Forsaken with Werewolf: The Apocalypse
- Mage: The Awakening with Mage: The Ascension
- Changeling: The Lost with Changeling: The Dreaming
- Hunter: The Vigil with Hunter: The Reckoning

The paired lines are different games.

## Catalog access

Inspect the local Books catalog first. If it is unavailable or the task requires current metadata, inspect the live Codex Books page and its `Rule Version` field directly.

If neither catalog is usable:
1. Prefer source metadata already stored in the repository or project library.
2. Prefer an official publisher/product page that explicitly identifies the edition.
3. Use a reliable indexed copy/reference only to establish edition identity.
4. If edition eligibility remains uncertain, do not treat the source as rules authority.

Never guess that a book is 2e-compatible merely because its publication date is recent.

## Offline catalog freshness

The local mirror is a research aid and may become stale. When freshness changes the answer, compare it with the live catalog and record the retrieval date or source used.
