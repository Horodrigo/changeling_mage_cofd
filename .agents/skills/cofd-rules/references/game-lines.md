# Chronicles of Darkness game-line map

Treat each line as mechanically independent unless an official rule explicitly shares or imports a mechanic.

| Line | Common shorthand | Do not confuse with |
|---|---|---|
| Chronicles of Darkness / Mortals | CofD | generic D&D-style "core rules"; Classic WoD |
| Vampire: The Requiem | VtR | Vampire: The Masquerade |
| Werewolf: The Forsaken | WtF | Werewolf: The Apocalypse |
| Mage: The Awakening | MtAw / MTAw | Mage: The Ascension |
| Promethean: The Created | PtC | unrelated "created" archetypes in other games |
| Changeling: The Lost | CtL | Changeling: The Dreaming |
| Hunter: The Vigil | HtV | Hunter: The Reckoning |
| Geist: The Sin-Eaters | GtSE / Geist | Wraith: The Oblivion |
| Mummy: The Curse | MtC | Mummy: The Resurrection |
| Demon: The Descent | DtD | Demon: The Fallen |
| Beast: The Primordial | BtP | generic monster/beast classes |
| Deviant: The Renegades | DtR / Deviant | generic mutants from other systems |

Shorthand varies between communities and source databases. Resolve abbreviations from context and book metadata; do not assume an ambiguous acronym.

## Shared concepts

Attributes, Skills, Merits, Conditions, Tilts, Willpower, Health, Beats/Experience, Integrity-like traits, supernatural power traits, and similar concepts may appear across lines, but their exact mechanics can differ.

Shared name != shared implementation.

When designing code, model a concept as Core only if the project and official rules genuinely treat it as common.
