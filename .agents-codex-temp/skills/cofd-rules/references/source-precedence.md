# Source precedence and conflict handling

Use the narrowest applicable authoritative source.

## Default order

1. User-specified project behavior / project homebrew
2. Applicable official game-line 2e core book
3. Eligible official supplements for that game line (`Rule Version` 2 or 1 & 2)
4. Chronicles of Darkness core/common rules
5. Eligible official cross-line publications
6. Codex of Darkness as an index/reference
7. Secondary community references

## Conflict rules

- A specific game-line rule overrides a generic Core assumption when the line explicitly changes the mechanic.
- A later official clarification/erratum overrides earlier text when the clarification is clearly applicable.
- A project homebrew rule overrides official mechanics only inside the feature/homebrew scope where the project says it does.
- A summary site does not override the underlying official book.
- First-edition-only mechanics never resolve a second-edition ambiguity by default.

## When sources disagree

Report:
1. what each eligible source says;
2. which source is more specific or authoritative;
3. whether the project already chose one behavior.

Do not merge incompatible rules into a synthetic rule unless the user explicitly asks for a house rule.
